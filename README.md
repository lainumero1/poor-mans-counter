# Poor Man's Counter


Features: 
Increment how much you earn every second,
Display money earned every hour/day/week/fortnight/month
Helps you get through a day of work by seeing every dime going into your bank. 

<!-- Runs as webapp/Chrome extension -->

To use: 
Input your wage
Input how your wage is calculated
Input how long do you work in a day (optional)
Input how long do your work in a week (optional)
